# 📄 Mi Currículum Web Responsivo

Este proyecto es una versión web y completamente responsiva de mi currículum profesional. Ha sido diseñado con una estética sobria en tonos azules, manteniendo una estructura de dos columnas optimizada para su visualización tanto en pantallas de escritorio como en dispositivos móviles.

---

## 🛠️ Tecnologías Utilizadas

Para el desarrollo y diseño de este sitio web se utilizaron las siguientes herramientas:

*   **HTML5:** Para la estructuración semántica del contenido.
*   **SCSS (Sassy CSS):** Para la gestión avanzada de estilos mediante el uso de variables (paleta de colores), anidamiento y un diseño adaptable basado en Flexbox y CSS Grid.
*   **FontAwesome (Opcional):** Para la integración de iconos limpios en la sección de contacto.

---
